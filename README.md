# How fast does coffee cool?

A tiny, made-up research project for the aisignoff workshop. It has the parts a real one has: lab notes, raw
data, an analysis script, results and a draft abstract.

| Folder | Contents |
|---|---|
| `notes/` | Lab notes: how the measurement was done |
| `data/` | The measured temperatures, every 3 minutes for an hour |
| `analysis/` | The script that fits Newton's law of cooling (`python analysis/fit_cooling.py`) |
| `results/` | What came out |
| `paper/` | A draft abstract |

How each part was made, and so what to declare, is in [HOW-THIS-WAS-MADE.md](HOW-THIS-WAS-MADE.md).
